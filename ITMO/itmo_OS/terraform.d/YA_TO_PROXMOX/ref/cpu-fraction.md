# Подход: `core_fraction` (доля CPU) в Yandex → Proxmox

## Yandex

```hcl
resources {
  cores         = 2
  core_fraction = 50   # гарантированная доля vCPU в процентах
}
```

## Proxmox

Прямого поля «проценты ядра» нет. Близкие механизмы:

- `cpu { limit = L }` — лимит CPU в процентах (0 = без лимита).
- `cpu { units = U }` — вес CPU в fair-scheduler (относительный приоритет между VM).

```hcl
cpu {
  cores = 2
  limit = 0     # или конкретный процент-лимит
  units = 100
}
```

## Решение

Точного эквивалента «процентов» нет. Использовать `limit` для лимита и/или `units` для
приоритета в зависимости от требований. Для обычных VM — `limit = 0` (без лимита).
