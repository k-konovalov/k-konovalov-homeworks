# Educational Pipeline

> Реализация плана `/ITMO/itmo_ai_how_to_learn/AI_02_using/educational-pipeline-plan.md`.
> Инфраструктура: `~/Documents/git/obsidian/pipeline/`.

## 0. Константы

- **Vault:** `OBSIDIAN_VAULT` env → `--vault` → `~/Documents/git/obsidian`
- **Теория:** `vault/Навыки/Обучение/<course-slug>/theory/<topic-slug>.md`
- **Вопросы:** соседний `<topic-slug>.questions.json`
- **Прогресс:** соседний `<topic-slug>.progress.json`
- **Zettelkasten:** `vault/Навыки/Обучение/<course-slug>/zettelkasten/`
- **Inbox:** `vault/inbox/`
- **Клиент:** `pipeline/quiz.py` (pool / log / report / import)
- **Лимит quiz:** 10 вопросов/день (C2)
- **Порог слабой темы:** avg score последних 5 ответов < 0.7 (B6)
- **Интервалы:** `1 → 2 → 4 → 7 → 15 → 30 → 60` дней (C1)

## 1. Триггеры

Активируется **только** при явном обращении:
«давай повторим», «давай учиться», «хочу повторить», «запусти пайплайн»,
«ежедневная сессия», «обучай меня», «время повторения», «запусти quiz».

Если пользователь просит **создать** тему — переход к сценарию «Сбор теории» (п. 3).

## 2. Порядок сессии (строго H2)

```
1) inbox/ → опрос по каждому файлу (если не пуст)
2) пул/прогресс    pipeline/quiz.py pool
3) quiz            до 10 вопросов, по 4 варианта
4) тяжёлый метод   по дню недели + самой старой теме
5) сводка          pipeline/quiz.py report  +  «что завтра»
6) git add + commit в vault (один коммит, I2)
7) бэкап SKILL.md  в obsidian/ как edu-pipeline.SKILL.md.bak (при изменениях)
```

**Пустое состояние (H3):** нет вопросов + inbox пуст → предложить **пропустить сессию**
и спросить, что добавить в материал (сбор теории → сценарий п. 3).

## 3. Сценарий: Сбор теории (создание темы)

Вход: диалог (текст, лекция, статья, код), либо файл из `inbox/`.

1. **Определи курс** (A2 слуг из git-папок ITMO:
   `itmo_base_python`, `itmo_GO`, `itmo_OS`, `itmo_security`, `itmo_base_algorithm`)
   ИЛИ новый курс (согласуй с пользователем).
   **Внешний материал** (не ITMO, не Practiceum): свободно размести в логически
   подходящей папке `Навыки/` (напр. `Навыки/Программирование/`) —
   без создания отдельного курса под одну тему.
2. **Определи тему.** 1 файл = 1 тема, 1 тема = 1 урок/лекция (A3, F6).
3. **Дедупликация (A4).** Прочитай существующие `theory/*.md` по связывающим
   ключевым словам (двуязычным: A1). Если совпадение ≥ 50%:
   - **НЕ редактируй** существующий файл.
   - Создай **новый файл** по той же теме (стек): `theory/<тема>-<дата>.md`
     или `theory/<тема>-v2.md`, `theory/<тема>-доп.md` — на твой выбор.
   - Обнови `index.md` (MOC) — добавь строку.
4. **Напиши `theory.md`** по шаблону:
   - `pipeline/templates/theory.md.template` (frontmatter `course/topic/date`,
     тело, `## Примеры`, `## Источники`, #теги внизу)
   - Язык: **русский**, термины — английский (A1)
5. **Сгенерируй `questions.json`:**
   - 3–7 вопросов на тему (достаточно для SM-2)
   - 4 варианта, один правильный
   - `id = <slug-темы>-NNN` (B1)
6. **Импорт в SM-2:** `python3 quiz.py import <slug-темы> <file>.json --course <slug>`
7. **Zettelkasten (G1–G3):**
   - Вычлени 2–5 ключевых понятий темы
   - Для каждого — файл `zettelkasten/<En-Title>.md` (G3: английское имя)
   - Внутри: 1–3 предложения, `[[...]]` к соседним карточкам
   - Ссылка на тему: `[[<slug-темы>]]` (G3)
   - Карточки — только навигация (G4), **не** в quiz/SM-2
8. **Обнови `index.md`** (MOC): строка `- [[<slug-темы>]] — <заголовок> — <краткое>`.
9. **Предложи пользователю** проверить:
   - теорию
   - вопросы (вы подтверждаете/правите — «Решённые вопросы» автоматизации)
   - zettelkasten (G2)

## 4. Inbox (H1)

При старте сессии:

1. `ls vault/inbox/`
2. Если **пусто** — пропускаем шаг.
3. Если **ненуль** — по каждому файлу:
   - Прочитай (head -40 / frontmatter / title)
   - Предложи пользователю выбрать:
     - **каталогизировать** → сценарий «Сбор теории» (п. 3)
     - **удалить** → `rm`
     - **пропустить** → оставить в inbox
4. **После решения** удали файл из `inbox/` (F3).
5. После всех решений — в п. 2.

## 5. Quiz (H2-3)

1. `python3 vault/pipeline/quiz.py pool`
   - stdout: JSON-массив `{id, topic, question, options, correct_index}`
   - лимит: 10 (C2)
2. Поочерёдно:
   - Покажи вопрос + 4 варианта
   - Поставь `score`: 1.0 если ответ совпал с `correct_index`, 0.0 иначе
   - Вызвали: `python3 vault/pipeline/quiz.py log <topic> <id> <score>`
3. После всех 10 — в п. 5 (тяжёлый метод).

### 5.1 Формат вопроса (вопрос с выбором)

Вопросы **задавать через интерактивный инструмент выбора** (opencode `question`),
а НЕ простым текстовым списком. Для каждого вопроса:
- `question` — текст вопроса
- `options` — 4 варианта как `label` + `description` (короткий пояснительный текст)
- `header` — короткая подсказка (≤ 30 символов)
- `multiple` — `false` (один правильный ответ)
- ответ пользователя возвращается готовым → сопоставить с `correct_index`

Обычный текстовый список (1/2/3/4) — только **фолбэк**, если интерактивный
инструмент недоступен.

## 6. Тяжёлый метод (H2-4, E1–E4)

| День (неделя) | Метод | Что делать пользователю | Роль ИИ |
|---|---|---|---|
| Пн | **Brain dump** | Выписывает всё, что помнит (без конспекта) | Сравни с `theory.md`, покажи пропуски, поставь score |
| Вт | **Фейнман** | Объясняй тему «как ребёнку» | Найди жаргон/пробелы, дай обратную связь, сохрани в `theory.md` как `## Своими словами` |
| Ср | **Элаборация** | Отвечай «почему?», «как?», свяжи с другим | Задавай вопросы-связки, поставь score |
| Чт | Повтор Пн | — | — |
| Пт | Повтор Вт | — | — |
| Сб | Повтор Ср | — | — |
| Вс | **Свободное** | Любой метод, пропуск по желанию | Помощь по запросу |

**Выбор темы (E1):** минимальный `interval_days` из SM-2 пула на сегодня.
**Порядок (E2):** после quiz (H2-4).
**Оценка (E3):** ИИ ставит `score` сам, финально, без спора.
**Лог:** `python3 quiz.py log <topic> <id> <score> --type brain_dump|feynman|elaboration`

## 7. Сводка (I1)

1. `python3 vault/pipeline/quiz.py report`
2. Печатаем:
   - **Пройдено:** N тем / M вопросов
   - **Accuracy (средняя score по последним 5):** X%
   - **Слабые места:** список `topic/slug` (avg5 < 0.7)
   - **Что завтра:** кол-во due + 1–2 темы
   - **«Ещё раз пройди...»:** 1 тема (на выбор ИИ)

## 8. Git (I2)

**Один коммит в конце сессии** (по решению #5):

```bash
git -C ~/Documents/git/obsidian add inbox/ pipeline/ Навыки/Обучение/<course>/
git -C ~/Documents/git/obsidian commit -m "vault: <course>/<topic> — save|quiz|method|report"
```

**Формат сообщения:** `vault: <course>/<topic> — <действие>`
где `<действие>` ∈ `{save, quiz, method, report, cleanup}`.

**Правило:** не коммитить до финальной сводки; один коммит на сессию.
