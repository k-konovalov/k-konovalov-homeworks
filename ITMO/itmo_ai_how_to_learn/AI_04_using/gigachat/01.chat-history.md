Все 8 ресурсов упали с ошибкой HTTP 401 — Authentication failed при попытке загрузить файлы с debian.org и ubuntu.com.

Проблема в том, что `proxmox_download_file` загружает файлы **на Proxmox-сервер** (192.168.174.100), а не с вашей машины. Ошибка HTTP 401 означает, что **Proxmox-сервер не может получить доступ к этим URL** — зеркала блокируют запросы без специального User-Agent.
